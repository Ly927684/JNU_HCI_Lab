# JNU HCI Lab

公开访问：https://ly927684.github.io/JNU_HCI_Lab/

江南大学人机交互研究团队。中英双语，主页、研究团队、研究项目、学术发表。含李阳 16 篇论文。

## 内容维护

团队编辑后台：https://jnu-hci-lab.sleekeel31.chatgpt.site/admin

由管理员添加团队成员邮箱，成员各自登录后编辑并发布。网页每次打开读取后台已发布内容；后台暂不可用时显示随网页保存的初始内容。腾讯文档文件夹暂未接入自动同步。

## 代码维护

index.html 为包含脚本、样式和初始照片的独立部署文件。可编辑 React / TypeScript 源码见 source-code.zip。后端仍托管在原云端；公开仓库不包含密钥或账号授权数据。
